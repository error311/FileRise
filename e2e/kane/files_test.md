# Create a folder and a file

## Create the first user and log in
Type "samrivera" as the Username and "FileRise-Test-2026" as the Password, then click "Save User".
Type "samrivera" as the User and "FileRise-Test-2026" as the Password, then click "Login".
Verify the file list shows "Files in (root)".

## Create a folder
Click the "New" button above the file list, then click "Create Folder".
Type "Projects" as the folder name and click "Create".
Verify "Projects" appears under "Folder Navigation & Management".

## Create a file
Click the "New" button above the file list, then click "Create File".
Type "notes.txt" as the file name and click "Create".
Verify "notes.txt" is listed in the file list.
