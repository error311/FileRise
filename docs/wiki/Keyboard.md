# Keyboard shortcuts

A feature of the interface is using keyboard shortcuts.

Press `?` to show help for keyboard shortcuts.


## Keys and their actions

|Key            |Action    |
|---------------|----------|
|/              |Search    |
|?              |Help      |
|Del            |Delete    |
|F2             |Rename    |
|F3             |Preview   |
|F4             |Edit      |
|F5             |Copy      |
|F6             |Move      |
|F7             |New folder|
|F8             |Delete    |
|Ctrl/Cmd+Shit+N|New folder|
